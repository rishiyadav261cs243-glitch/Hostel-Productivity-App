About this app

Project: Impact of Hostel Environment on Student Study Productivity
Course: Data Science with AI, NITK Surathkal
Made by Rishi Yadav (261CS243), Section 14, Computer Science
Guide: Dr. Aishwarya Balakrishnan

How it works: the final tuned SVM (C = 100, gamma = 0.01, balanced class weights) was run on all 1,250 possible answer combinations, and this page shows those exact predictions. Test accuracy 0.83, macro-F1 0.77; repeated cross-validation accuracy 0.81.

  • Data: survey of 634 hostel students (self-reported).
  • Mid is the model’s weakest class.
  • This is a screening tool, not a judgement on any student.
  • Built with help from an AI assistant (Claude).
