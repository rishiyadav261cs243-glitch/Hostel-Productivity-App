Hostel Productivity Predictor

Choose your room conditions. The predicted study productivity updates instantly.

How it works: the final tuned SVM from this project (C = 100, gamma = 0.01, balanced class weights) was run on all 1,250 possible answer combinations, and this page shows those exact predictions. Test accuracy 0.83, macro-F1 0.77. Mid is the model’s weakest class. This is a screening tool based on self-reported survey data, not a judgement on any student.
